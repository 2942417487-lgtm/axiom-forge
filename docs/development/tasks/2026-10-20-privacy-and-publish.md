## 范围

对 codex/development-docs-and-skills 的现有文档／工程技能工作集检查真实 API Key、Token、密码、私钥、审批资料、私人运行记录和不应共享的本机配置。仅扫描候选 Git 文件及可达提交／标签内容；被忽略的真实凭据不打开或复制，审批 Key 不读取。疑似发现只记录文件、行号和类别，不输出原值。

通过本地检查后，仅提交明确文件，推送当前分支并创建 PR；再核对远端文件清单、精确提交、差异与扫描覆盖。没有未解决隐私发现且远端内容与已检查本地对象一致时，将合并父提交绑定到已审核 head 和主线基线，并确认合并树一致。GitHub 合并接口不提供本次所需的作者邮箱参数，因此内容提交与本地合并提交均显式指定 noreply；复核远端 head／主线及合并对象后非强制推送，由 GitHub 确认 PR 已合并。保护规则拒绝时停止，不绕过。保留旧分支、worktree 和缓存，不强推、清理或重写历史，不操作正式世界或调用研究 API。

起始集成基线为 5958e41ffd64c0d3c69b266e0061203df2fe25ac，原文档整理及双轴审查记录见 [整理任务](2026-10-20-docs-and-skills.md)。本任务覆盖新的发布／合并授权，不改写原任务完成时“尚未发布”的历史记录。

PR 描述使用 af-dev-pr，保持文件职责、实际验证和影响说明；隐私结果写在本目录，不进入模块 README。
