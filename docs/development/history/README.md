# 历史记录阅读说明

[阶段记录](phases/phase-0.md) 与其他 `phases/` 文件保留当时交付／验收的日期和边界；内容可能描述后来已实现的“未来阶段”。它们不代表当前功能状态或新的执行授权。

[过去 README 中的开发说明](readme-development-notes.md) 保存本次迁出的进度、联调与排障片段，并记录原始 Git 基线。[迁移清单](../migration-map.json) 给出旧路径、新路径和迁移前字节哈希；完整原件仍可通过相应 Git 提交读取。

[指南与契约的旧执行说明](guide-and-contract-notes.md) 保留从现行操作文档迁出的验收与旧交付状态，供按需追溯。

接续开发先读 [CURRENT](../CURRENT.md)；按 [CHANGELOG](../CHANGELOG.md) 定位具体任务。使用产品时以 [操作指南](../../README.md) 与模块 README 为准。历史记录中的命令、个人路径和阶段性额度不直接用于正式世界。
