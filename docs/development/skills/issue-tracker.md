# 工程任务跟踪

沿用仓库的本地 Markdown 任务说明，统一放在 `docs/development/tasks/`。本次任务见 [文档与技能整理](../tasks/2026-10-20-docs-and-skills.md)。

每项任务记录用户请求、获准范围、基线、交付、实际验证及未完成项。CURRENT 只指向当前任务，历史任务保留其执行日期与原验收范围。不要把计划写成执行授权，或把过去的临时费用／发布授权沿用到新任务。

PR 仍是人工 review 与集成入口；创建 Issue、发布 PR、发送评论和合并分别依用户授权。技能不能因发现 GitHub remote 而自动创建远端任务。本地任务已能表达本轮需求时，不要求用户重新配置 tracker。
