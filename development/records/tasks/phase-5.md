# Phase 5：独立工具层

用户授权推进 Phase 5；本阶段从已合并的 PR #3 / main 开始，使用功能分支交付待审查 PR，不自动合并。

## 已确认范围

- 接入公开论文检索：Crossref 查询与 DOI metadata、arXiv 查询。
- 接入有明确来源/时间/内容哈希的 Web 读取；通用搜索仅建立可配置接口，服务选定后启用。
- 接入受限文件读写，以及 UTF-8 文本、PDF、DOCX 文本读取。
- Canon/Evidence 读取固定快照；写操作只保存当前 AgentRun 的 Evidence 草稿和 pending Canon 提案，不应用正式知识库。
- 接入只读 Git 查询；研究角色没有 Git mutation。
- 接入由操作者登记并审核的 Python 脚本调用接口；通用 CalculationRequest 执行器、具体算法与 MATLAB Adapter 后续再建。
- 统一工具定义、输入校验、业务上下文、成功/失败状态、真实调用回执和私有暂存结果；不绑定厂商 SDK 或 Agent。

## 边界与验收

- Runtime 与身份认证尚未实现；工具 Context/可见资料/脚本登记只能由可信宿主建立，不能采信 Agent 自报权限。
- 按当前 AgentRun 隔离文件，拒绝越界路径与链接；Canon 查询只返回明确选中的实体。独立阶段不接收其他岗位的文件。
- 网络请求只访问宿主允许的 HTTPS 域名和公开地址，限制重定向、响应大小与超时；网页/论文内容视为资料，不是指令。
- Python 仅运行预先审核、哈希匹配的登记脚本，JSON 输入输出；没有 OS 沙箱时不向 Agent 提供自动执行能力。
- 不因搜索命中、摘要读取或填入回执字段，就将科学主张标为已验证。
- 测试覆盖路径/身份/阶段/权限、网络错误与来源记录、文件读取、暂存不可覆盖、Python 登记/哈希/超时/输出、Git 拒绝写操作；真实公开接口联调结果与离线测试分开记录。
- 生产 world 保持为空；保持原有契约和基础测试通过，交付明确的实现与未验证项。
